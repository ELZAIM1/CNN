# 🧠 CNN Handwritten Digit Classifier

This project implements a **Convolutional Neural Network (CNN)** to classify handwritten digits (0–9) using the **MNIST dataset**.

The full implementation is provided in a single Jupyter Notebook: `CNN.ipynb`.

---

## 📌 Overview

- Build a CNN model using PyTorch
- Train the model on MNIST dataset
- Evaluate model performance
- Visualize predictions

## 🧠 Model Details

The CNN includes:
- Convolutional layers
- ReLU activation
- MaxPooling
- Fully connected layers
- Output layer for 10 classes (digits 0–9)
